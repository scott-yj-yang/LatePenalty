# Installation

## Requirements

- Python 3.12 or higher

## Install from PyPI

```bash
pip install LatePenalty
```

## Install from source

```bash
git clone https://github.com/scott-yj-yang/LatePenalty.git
cd LatePenalty
pip install -e .
```

## Dependencies

LatePenalty depends on:

- [canvasapi](https://github.com/ucfopen/canvasapi) — Python wrapper for Canvas LMS REST API
- [pandas](https://pandas.pydata.org/) — Data manipulation
- [numpy](https://numpy.org/) — Numerical computing
- [pyyaml](https://pyyaml.org/) — YAML parsing for late exceptions
- [requests](https://requests.readthedocs.io/) — HTTP requests for GitHub validation
- [nbformat](https://nbformat.readthedocs.io/) — Jupyter notebook parsing
